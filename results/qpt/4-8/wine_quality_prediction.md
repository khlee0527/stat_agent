# 와인 품질 점수 예측과 우수 와인 선별

## 분석 개요

레드 와인 1,599개와 화이트 와인 4,898개, 총 6,497개 관측치를 결합했다. 한 행은 와인 한 표본이다. 품질 점수(`quality`)를 예측할 때 입력으로 사용한 변수는 11개 물리·화학적 측정값과 와인 종류 표시 변수다.

우수 와인은 `quality ≥ 7`로 정의했다. 7점은 이 실습에서 정한 **운영 기준**이며, 보편적이거나 공식적인 품질 경계라는 뜻은 아니다. 레드 와인 중 우수 와인은 217/1,599(13.6%), 화이트 와인은 1,060/4,898(21.6%)였다.

## (a) 회귀 문제와 분류 문제

### 품질 점수 회귀

반응변수는 숫자형 `quality`다. 와인의 측정값으로 품질 점수 자체를 예측한다. 예측값은 점수 척도의 수치로 해석한다.

### 우수 와인 분류

반응변수는 다음과 같이 이진화했다.

```
y = 1  if quality >= 7
y = 0  if quality < 7
```

이 분류에서는 7점 이상을 우수 와인으로 취급한다. 회귀 점수를 이 기준으로 다시 나누는 것과 달리, 분류 모형은 처음부터 이진 결과를 예측하도록 학습한다.

## (b) 선별 규칙과 검증 자료 성능

레드·화이트 자료를 합친 뒤, 양성 여부(`quality ≥ 7`)를 기준으로 층화하여 학습 60%, 검증 20%, 최종 평가 20%로 나눴다. 난수 시드는 42로 고정했다. 분할 크기는 학습 3,898개, 검증 1,299개, 최종 평가 1,300개였다. 두 모형은 동일한 입력 변수와 분할을 사용했다.

두 모형 모두 랜덤포레스트를 사용했다(`n_estimators=400`, `min_samples_leaf=2`, `random_state=42`). 회귀 모형은 예측 점수가 7 이상이면 선별했다. 분류 모형은 우수 와인 예측확률을 사용했다.

분류 모형의 기준 확률은 검증 자료에서 F1 점수가 가장 높아지는 값으로 정했다. 이 기준은 0.366이었다. 기준 확률 0.5 결과도 비교 목적으로 함께 제시한다.

검증 자료 1,299개 중 실제 우수 와인은 255개였다.

| 모형과 선별 기준 | Precision | Recall | F1 | 선별 수 |
|---|---:|---:|---:|---:|
| 회귀: 예측 점수 ≥ 7 | 82.9% | 11.4% | 20.0% | 35 |
| 분류: 예측확률 ≥ 0.5 | 79.8% | 54.1% | 64.5% | 173 |
| 분류: 예측확률 ≥ 0.366 | 68.3% | 71.0% | 69.6% | 265 |

Precision은 선별한 와인 중 실제 우수 와인의 비율이고, recall은 실제 우수 와인 중 선별된 비율이다. 회귀 규칙은 정밀도가 높았지만 실제 우수 와인의 대부분을 놓쳤다. 분류 확률 기준을 0.5에서 0.366으로 낮추면 recall은 높아지고 precision은 낮아졌다.

0.366은 검증 자료의 F1을 최대화해 선택한 값이므로, 같은 검증 자료에서 계산한 성능은 다소 낙관적일 수 있다. 이 기준은 최종 평가 자료를 보고 조정하지 않는다.

## (c) 전체의 10%만 추가 검사할 수 있을 때

모형 선택 후 학습 자료와 검증 자료를 합쳐 각 모형을 다시 적합했다. 이후 최종 평가 자료 1,300개에서 각 모형의 예측 점수 순으로 상위 10%인 130개를 골랐다. 품질 정답은 이 최종 평가 성능 계산에만 사용했다. 고정된 검사 용량에 맞춰 순위로 130개를 선정했으므로, 분류 모형의 검증 기준 0.366을 최종 자료에 맞춰 바꾸지 않았다.

| 선별 순위에 사용한 점수 | 상위 130개 중 우수 와인 | 상위 10%의 우수 와인 비율 |
|---|---:|---:|
| 회귀 모형의 예측 품질 점수 | 101개 | 77.7% |
| 분류 모형의 우수 와인 예측확률 | 105개 | 80.8% |

최종 평가 자료 전체의 우수 와인 비율은 256/1,300(19.7%)이었다. 따라서 두 모형 모두 전체 자료보다 우수 와인의 비율이 높은 집단을 선별했다. 제한된 검사 용량에서 우수 와인을 최대한 많이 찾는 목적에는 상위 10%의 우수 와인 비율이 약간 더 높았던 **분류 접근**을 선택한다. 다만 차이는 130개 중 4개이므로, 이 한 번의 분할 결과만으로 큰 성능 차이가 있다고 보기는 어렵다.

## 해석상 유의점

- 분류의 양성 기준 `quality ≥ 7`은 실습에서 정한 운영 기준이다.
- 상위 10% 결과는 이 데이터와 분할에서의 선별 성능이다. 다른 시기나 생산 환경에도 같은 성능이 유지된다고 보장하지 않는다.
- 10% 검사 예산에서 중요한 지표는 정해진 수만큼 선별했을 때 우수 와인이 차지하는 비율이다. 분류 기준을 정답 자료에 맞춰 조정하는 것과, 예측 점수 순위로 검사 용량만큼 선별하는 것은 구분해야 한다.
