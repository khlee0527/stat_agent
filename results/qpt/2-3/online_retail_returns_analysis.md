# 문제 2-3. 매출을 계산했는데 음수가 나왔다면?

데이터: `Online Retail.xlsx`  
분석 단위: 주문에 포함된 상품 한 항목(주문 라인)  
라인 금액: `Quantity × UnitPrice`

## (a) 행의 의미와 예외 기록

자료는 541,909행과 25,900개의 고유 `InvoiceNo`로 구성된다. 주문번호별 행 수를 집계하면 20,059개 주문에는 여러 행이 있고 5,841개 주문에는 한 행만 있다. 예를 들어 `536365` 주문에는 상품 코드와 수량, 단가가 서로 다른 상품 라인이 7개 있다. 따라서 한 행은 주문 전체가 아니라 **주문에 포함된 상품 한 항목**을 나타낸다. `Quantity`는 그 항목의 수량, `UnitPrice`는 개당 가격이다.

| 기록 기준 | 행 수 | 고유 주문 수 | 관찰 |
|---|---:|---:|---|
| `InvoiceNo`가 `C`로 시작 | 9,288 | 3,836 | 취소 표시로 볼 수 있는 주문 라인 |
| `Quantity < 0` | 10,624 | 5,172 | 음수 수량 라인 |
| `UnitPrice <= 0` | 2,517 | 2,157 | 0 또는 음수 단가 라인 |

`C`로 시작하는 행 9,288개는 모두 음수 수량이며, 해당 주문은 3,836개다. 반면 취소 표시가 없는 주문에도 음수 수량 행이 1,336개 있다. 이 1,336개 행의 단가는 모두 0이다.

비양수 단가 행 2,517개 중 2,515개는 단가가 0이고, 2개는 단가가 음수다. 음수 단가 2개는 2011년 8월의 `Adjust bad debt` 기록으로, 각 행의 수량은 1, 단가는 -11,062.06이다. 두 행의 금액 합계는 -22,124.12다. 단가가 0인 행은 금액에 기여하지 않는다. 따라서 음수 수량이나 비양수 단가를 모두 일반 판매로 해석하면 안 된다.

## (b) 정상 판매액·취소·반품액·순거래액 규칙

각 행의 금액을 `Quantity × UnitPrice`로 계산하고, `InvoiceDate`가 속한 월로 집계했다.

- **정상 판매액:** `InvoiceNo`가 `C`로 시작하지 않고 `Quantity > 0`, `UnitPrice > 0`인 행의 금액 합계.
- **취소·반품 관련 금액:** `InvoiceNo`가 `C`로 시작하거나 `Quantity < 0`인 행의 금액 합계. 부호를 유지하므로 차감액은 음수다. 0원 단가인 음수 수량 기록도 이 범주에 포함하지만 금액은 0이다.
- **대손 조정액:** `UnitPrice < 0`인 행의 금액 합계. 취소·반품과 구분해 별도로 표시한다.
- **순거래액:** 모든 행의 `Quantity × UnitPrice` 합계. 이 자료에서는 정상 판매액 + 취소·반품 관련 금액 + 대손 조정액과 일치한다.

## (c) 음수 수량을 삭제했을 때와 유지했을 때

음수 수량을 유지하면 모든 라인의 금액을 합산한다. 삭제하면 `Quantity < 0`인 라인을 제외하고 나머지 라인의 금액을 합산한다. 삭제 후에도 양수 수량의 음수 단가 조정 두 건은 남아 순거래액에서 차감된다.

음수 수량 행 10,624개를 삭제하면 순거래액이 총 896,812.49 증가한다. 이 차이는 양수 단가의 취소·반품 금액이 사라지기 때문이다. 음수 수량이지만 단가가 0인 1,336개 행은 삭제되어도 금액 차이를 만들지 않는다. 삭제 효과가 가장 큰 달은 2011년 12월로, 순거래액이 205,124.67 증가한다. 음수 수량을 삭제한 순거래액은 전체 기준으로 유지한 금액보다 약 9.2% 높다.

판매 활동과 순거래 실적은 구분해 보고하는 것이 적절하다.

- **판매 활동:** 정상 총판매액 10,666,684.54와 정상 판매수량 5,588,376개를 보고한다. 이 총판매 지표는 음수 수량 라인을 제거해도 변하지 않는다.
- **취소·반품:** 차감 금액 -896,812.49와 수량을 별도로 보고한다. `C` 주문과 그 밖의 음수 수량을 구분하면 취소 표시가 없는 음수 수량 1,336건도 확인할 수 있다.
- **순거래 실적:** 취소·반품을 반영한 뒤 대손 조정액 -22,124.12를 별도로 표시하고, 최종 순거래액 9,747,747.93을 보고한다.

이 파일에는 결제·입금 시점이 없으므로 순거래액을 현금흐름으로 해석할 수는 없다. 금액 단위도 별도 통화 열에 명시되어 있지 않아 원자료의 단위로 제시했다.

## 재현용 pandas 코드

```python
import pandas as pd

df = pd.read_excel("Online Retail.xlsx")
df["InvoiceNo"] = df["InvoiceNo"].astype(str)
df["Month"] = df["InvoiceDate"].dt.to_period("M").astype(str)
df["LineAmount"] = df["Quantity"] * df["UnitPrice"]

is_cancel_invoice = df["InvoiceNo"].str.startswith("C")
normal = (~is_cancel_invoice) & (df["Quantity"] > 0) & (df["UnitPrice"] > 0)
cancel_return = is_cancel_invoice | (df["Quantity"] < 0)
adjustment = df["UnitPrice"] < 0

df["NormalSales"] = df["LineAmount"].where(normal, 0)
df["CancelReturn"] = df["LineAmount"].where(cancel_return, 0)
df["Adjustment"] = df["LineAmount"].where(adjustment, 0)
df["NetKept"] = df["LineAmount"]
df["NetAfterDeletingNegativeQty"] = df["LineAmount"].where(df["Quantity"] >= 0, 0)

monthly = df.groupby("Month")[
    ["NormalSales", "CancelReturn", "Adjustment",
     "NetKept", "NetAfterDeletingNegativeQty"]
].sum()

monthly["IncreaseAfterDeletion"] = (
    monthly["NetAfterDeletingNegativeQty"] - monthly["NetKept"]
)
print(monthly.round(2))
```
